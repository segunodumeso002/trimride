# TrimRide Investor Deck Draft

## Slide 1: Cover
TrimRide
Real-Time Barber Marketplace
Customer + Barber Apps Live Today
Prepared: May 2026

## Slide 2: Problem
Barber bookings are still fragmented and slow.
Customers struggle with:
- Delayed responses
- Unclear arrival times
- Poor visibility after booking
Barbers struggle with:
- Unpredictable demand
- Missed nearby requests
- No modern dispatch workflow

## Slide 3: Solution
TrimRide is a two-sided, real-time marketplace for grooming-on-demand.
- Customer app for request and live tracking
- Barber app for online status and incoming requests
- Shared backend with real-time events, booking lifecycle, and push messaging

## Slide 4: Product Proof (What Works Now)
Working now in live dev environment:
- Customer and barber authentication
- Customer booking request flow
- Barber online dashboard and request queue
- Booking status progression
- Real-time socket updates
- Push notification token registration and delivery pipeline validation

## Slide 5: Customer Experience
Current customer value:
- Browse and request quickly
- Service filters and best-match card
- Current booking card with status updates
- Live tracking handoff after confirmation
- Cleaner language and UX hierarchy for confidence and clarity

## Slide 6: Barber Experience
Current barber value:
- Online or offline availability control
- Incoming request visibility
- Fast action surfaces for daily operations
- Busy-area and promotions entry points
- Cleaner empty, loading, and status messaging

## Slide 7: Technology and Readiness
Architecture in place:
- React Native customer app
- React Native barber app
- Node and Express API backend
- PostgreSQL data layer
- Socket-based real-time updates
- Firebase push plumbing
Execution readiness:
- Automated dev stack startup and health checks
- Regression checks run repeatedly during iteration

## Slide 8: Business Model
Revenue model:
- Commission per completed booking
- Priority placement or featured barber subscriptions
- Promotions tools for barber growth campaigns
Future expansion:
- In-app wallet and subscriptions
- Team and salon management packages

## Slide 9: Go-To-Market Plan
Phase 1: Single city pilot
- Focused neighborhoods
- Curated early barber supply
- Fast customer response loop
Phase 2: Repeatable expansion
- Zone-by-zone rollout
- Referral loops
- Performance marketing only after retention targets are met

- Move from validated MVP to scalable launch-ready platform
